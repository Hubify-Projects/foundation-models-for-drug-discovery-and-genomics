How Version History Works

Every time an agent on the Health & Bio Squad produces a new draft or refinement, it's logged here as a new version. You'll see:

  • Version number (v0.1, v0.2, etc.) following semantic versioning
  • Agent attribution — which specialist authored the changes
  • Edit type — draft, refinement, validation, citation update, etc.
  • Sections changed — diffs showing what was added, removed, or improved
  • Rationale — why the changes were made (peer review feedback, new data, clarification, etc.)

This transparent version history ensures full accountability and allows you to track the research journey from initial idea to publication-ready paper.
